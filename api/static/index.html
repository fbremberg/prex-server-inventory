Los cinco datos solicitados

Procesador, procesos corriendo, usuarios con sesión abierta, nombre y versión del sistema operativo. Consulta del último envío por IP y descarga JSON.

Consultar lee información guardada. Para obtener datos nuevos, ejecutá el agente en el equipo o esperá su próxima ejecución programada.

Ingresá una IPv4 para consultar su último envío.

Este límite solo clasifica los equipos del dashboard. La frecuencia de envío se configura en la tarea programada del agente.

La vigencia indica cuándo llegó el último envío. Un equipo sin reportes recientes puede estar apagado, desconectado o tener el agente detenido. Solo se conocen los equipos que ya reportaron.
